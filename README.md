# The Valhalla Archive

The official unofficial almanac of a College Football 25 dynasty: the Cleveland State Vikings, plus OHIO and M-OH.

> Unofficial fan site. Not affiliated with Cleveland State University, any other school, EA Sports or the NCAA. All dynasty content is fictional.

## Where things live
- **This folder** (`Documents\valhalla-archive`) holds the whole website: code, data and clips.
- **GitHub** ([captiancernal/valhalla-archive](https://github.com/captiancernal/valhalla-archive)) keeps the online copy and hosts the live site.
- **Google Drive** ("The Valhalla Archive" folder) holds the things that don't belong online: dated tracker downloads, raw clips, PDFs and backups.
- **Your tracker** stays exactly where it is. The site only ever reads a copy of it.

## Folders in this project
| Folder | What's in it |
|---|---|
| `source/` | Dated copies of your tracker. Stays on your computer and is never uploaded. |
| `data/` | The clean data tables built from the tracker, plus the list of data fixes you approved |
| `content/split-decision/` | The Split Decision columns and the columnists' character bible |
| `content/clips/` | Highlight clips. Drop new MP4s in `incoming/`. |
| `scripts/` | The tools that read the tracker and build the site |
| `site/` | The website itself |
| `docs/` | The master plan for the project |

## How to update the site
You'll get a one-command update once it's built (`/update-archive`). Instructions will go here.
